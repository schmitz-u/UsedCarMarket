🏍️ Honda Gold Wing Model System (Generations & Variants)
Legend
Tour = full‑dress touring (top case, large screen, max comfort)

Bagger = no top case, lower screen, lighter, sport‑touring character

📘 Compact Table: Gold Wing Generations by Model Year
1) Classic Flat‑Four Era (GL1000 / GL1100 / GL1200)
Generation	Years	Engine	Tour Version	Bagger Version	Notes
GL1000	1975–1979	999cc flat‑4	No	No	Naked long‑distance bike, no factory fairing
GL1100	1980–1983	1085cc flat‑4	Interstate / Aspencade	No	First factory touring equipment
GL1200	1984–1987	1182cc flat‑4	Interstate / Aspencade / LTD	No	More luxury, EFI on LTD


2) Six‑Cylinder Touring Era (GL1500)
Generation	Years	Engine	Tour Version	Bagger Version	Notes
GL1500	1988–2000	1520cc flat‑6	Gold Wing SE / Aspencade	No	First 6‑cyl, reverse gear, iconic luxury


3) First GL1800 Era (Aluminum Frame)
Generation	Years	Engine	Tour Version	Bagger Version	Notes
GL1800 (Gen 1)	2001–2010	1832cc flat‑6	Full Tour	No	Major leap: aluminum frame, handling focus
GL1800 (Gen 1.5)	2012–2017	1832cc flat‑6	Full Tour	F6B (2013–2016)	F6B = first modern Bagger


4) Modern Gold Wing (Completely New Platform)
Generation	Years	Engine	Tour Version	Bagger Version	Notes

GL1800 (Gen 2.1)	2021–2023	1833cc	Tour (bigger trunk)	Bagger	Comfort updates, audio improvements
GL1800 (Gen 2.2)	2024–2026	1833cc	Tour	Bagger	Minor refinements, new colors, software tweaks


🧭 Quick Summary (Very Compact)
Tour models exist from GL1100 onward, always the luxury flagship.

Bagger models appear only in:

F6B (2013–2016)

Gold Wing Bagger (2018–today)

Major platform changes:

1975 → first Gold Wing

1988 → GL1500

2001 → GL1800 (aluminum frame)

2018 → new GL1800 (lighter, DCT, modern electronics)
